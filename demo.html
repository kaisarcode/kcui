Styling layers

KCUI provides stable semantic structures with minimal classes. Themes style these structures without requiring different HTML.

  1. Semantic HTML defines the content and its meaning.
  2. kcui.css provides the structural base and default variables.
  3. Optional modules add reusable capabilities.
  4. UI themes change shape, spacing, typography, and presentation.
  5. Color palettes change the shared color variables independently of the UI theme.
  6. Product CSS applies the final, project-specific adjustments.

UI themes and palettes can be combined freely. This demo uses the same markup for Base and Mobile; the selector changes only the active UI theme.
