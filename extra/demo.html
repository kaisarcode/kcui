Tabs

Accessible tabs using ARIA roles inside .tabs container.

Overview

The tabs component provides a standard accessible tab interface.

It uses ARIA roles for screen reader support and CSS for visual presentation.

Usage

Wrap tabs in a container with .tabs class.

Use role="tablist", role="tab", and role="tabpanel".

Toggle aria-selected and hidden with JavaScript.

Properties

No custom properties. Tabs inherit KCUI core variables.

Colors

Color palettes that override KCUI's color variables without providing a finished visual design.
